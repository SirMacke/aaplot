# aaplot

Terminal dashboard for [Artificial Analysis](https://artificialanalysis.ai) model data — cost vs intelligence quadrant charts, rankings, and comparisons, all in your terminal. Unofficial; not affiliated with Artificial Analysis.

**Status: under construction.** See [PLAN.md](./PLAN.md).

## Install

```
npm i -g aaplot
aaplot
```

Requires a free API key from [artificialanalysis.ai/data-api](https://artificialanalysis.ai/data-api). Set it with `AA_API_KEY` or paste it at the onboarding screen on first run.

Data: [Artificial Analysis](https://artificialanalysis.ai). Licensed under their [API terms](https://artificialanalysis.ai/data-api/docs).
